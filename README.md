# FastProxysByTai

A responsive black-and-white OLED browsing portal with multiple search engines, website shortcuts, and membership preview cards.

## Features
- Search or enter a web URL; opens in a new tab.
- Google, DuckDuckGo, Startpage, Bing, Brave Search, and Ecosia.
- Quick links to Wikipedia, GitHub, YouTube and MDN Web Docs.
- Free, Plus, and Pro plan previews.
- Owner sign-in placeholder.
- Dark OLED design with mobile support.

## Deploy on Vercel
Import `taithedev/Fastproxysbytai` at https://vercel.com/new. Set **Framework Preset** to **Other**, root directory to `/`, and leave build command empty. Deploy.

## Important
Membership billing, server-side account entitlements, and owner authentication have not been implemented. The owner code is **not** stored in the public website. Do not use client-side codes as proof of ownership. This website is a browsing/search portal, not an HTTP proxy, VPN, or unblocking service.
